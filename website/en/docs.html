Setup and system boundaries.

Documentation for the 2026-10-18 checkpoint. KADR is an Early Access / Research Prototype.

01

Portable installation

  1. Install a licensed KOMPAS-3D and launch it once.
  2. Verify the downloaded archive SHA-256.
  3. Extract the complete directory to NTFS or exFAT.
  4. Run START_KADR.cmd --check-only.
  5. After a successful check, run START_KADR.cmd.
KOMPAS-3D and its license are not included. Once the local model is present, KADR does not require the Internet for local inference.
02

System requirements

OSWindows 10/11 x64
CADKOMPAS-3D; live-tested on v23
RAM16 GB or more recommended
GPUNVIDIA with 8 GB VRAM recommended; CPU is slower
Disk10+ GB for the portable bundle plus project storage
03

KOMPAS workflow

KADR connects through the Windows COM API. Close stalled KOMPAS instances before diagnostics. Every generated model requires visual and engineering review. Developer live scripts run separately and are intentionally excluded from ordinary CI.

05

Known limitations

  • Native dynamic kinematics, collision detection, and clearance checks are not VERIFIED yet.
  • OCR/Vision cannot guarantee every dimension association and must not invent values.
  • Production drawings and calculations require engineer review.
  • Other KOMPAS versions need separate live validation.
  • Complex nested assemblies and the V6 project are planned, not shipped capabilities.
