01 / Возможности

Один контур инженерной работы.

KADR связывает язык, инженерные данные и нативные документы КОМПАС. Статус каждой функции указан честно.

IMPLEMENTED01

Text-to-CAD

Команды на русском языке превращаются в типизированный план, а неоднозначные параметры — в точные вопросы.

«Создай вал Ø30, L100…»→Feature Plan
IMPLEMENTED02

Параметрические M3D

Детали, операции, ревизии и проверка геометрии через нативный COM API.

LIVE VERIFIED03

Сборки A3D

Компоненты, координаты и базовые сопряжения. Дискретные положения проверены на эталонном механизме.

EXPERIMENTAL04

Drawing Reader

OCR, чтение видов и разрезов, provenance и блокировка построения при неполных данных.

EXPERIMENTAL05

Spatial Engine

Связывает размеры с областями, видами и CAD-топологией, не выдавая гипотезы за факты.

IMPLEMENTED06

CDW Generation

Создание нативного чертежа из текущей модели с именованными видами и метаданными.

EXPERIMENTAL07

Kinematics Engine

Типизированные ограничения и аналитические положения. Нативная динамика — следующий контрольный этап.

LOCAL08

Qwen + Ollama

Локальная обработка запросов без передачи инженерных данных во внешний AI API.

03 / Документация

Запуск без догадок.

Portable остаётся локальным пакетом. КОМПАС-3D и его лицензия устанавливаются отдельно.

PowerShell
# Проверка portable
.\START_KADR.cmd --check-only

# Запуск
.\START_KADR.cmd

# Запуск тестов исходной версии
.\.venv313\Scripts\python.exe -m unittest \
  discover -s tests -p "test_*.py" -v
